# Usage

## Save a link

1. Open SaveBuddy.
2. Enter an optional title.
3. Enter the URL.
4. Select **SAVE LINK**.

## Save the current tab

1. Open the page you want to save.
2. Open SaveBuddy.
3. Select **SAVE TAB**.

## Edit a link

1. Find the saved link.
2. Select **Edit**.
3. Update the title or URL.
4. Save the changes.

## Copy a URL

Select **Copy** beside a saved link.

## Delete a link

Select **Delete** beside a saved link.

## Delete all

Select **DELETE ALL** and confirm the action.
