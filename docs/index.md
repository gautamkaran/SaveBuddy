# SaveBuddy

A tiny Chrome extension for keeping the links you actually want to come back to.

Save any URL, save the tab you're on, then edit, copy, or delete your links from a small popup. Everything stays in your browser's local storage — no account, no cloud.

**Version:** `v1.0` · **License:** MIT

[Get Started](getting-started.md){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[View on GitHub](https://github.com/gautamkaran/SaveBuddy){: .btn .fs-5 .mb-4 .mb-md-0 }

## What it does

- Save a link with an optional title.
- Save the current tab in one click.
- Edit, copy, or delete saved links.
- Show each site's favicon next to its link.
- Open the popup with a shortcut (default `Alt+S`).
- Keep everything local — no account, no sync.

## Install in 30 seconds

1. Clone or download the repo.
2. Open `chrome://extensions/`.
3. Turn on **Developer mode**, then **Load unpacked** and pick the `extension/` folder.
4. Pin SaveBuddy to the toolbar.

Full instructions: [Installation](installation.md)
