# SaveBuddy

## Save useful links. Keep them organized.

SaveBuddy is a lightweight Chrome extension for saving and managing useful
web links directly from Chrome. Save a link, save the current tab, edit,
copy, or delete it — all from a small popup.

**Current version:** `v1.0` · License: MIT

## What SaveBuddy does

SaveBuddy keeps the workflow simple — save a useful page now, find it again
later.

- **Save a link manually** — enter a URL (and an optional title), then save.
- **Save the current tab** — one click saves the active tab's title and URL.
- **Edit saved links** — update the title or URL of any saved link.
- **Copy URLs** — copy any saved URL straight to the clipboard.
- **Delete links** — remove a single link, or all links at once.
- **Website favicons** — saved links show the favicon of their website.
- **Keyboard shortcut** — open the extension quickly with a keyboard shortcut.
- **Local storage** — saved links stay in your browser. No account, no cloud sync.

## Requirements

- Google Chrome (or a Chromium-based browser)
- The SaveBuddy source code

## Quick start

1. Clone or download the repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable **Developer mode**, then **Load unpacked** and select the `extension/`
   folder.
4. Pin SaveBuddy to your toolbar.
