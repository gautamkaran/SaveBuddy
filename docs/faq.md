# FAQ

## Do I need an account?

No.

## Can I save the current Chrome tab?

Yes. Use **SAVE TAB**.

## Can I edit saved links?

Yes.

## Can I copy a saved URL?

Yes.

## Can I delete all saved links?

Yes. Use **DELETE ALL** and confirm.

## Where can I change the keyboard shortcut?

Open:

```text
chrome://extensions/shortcuts
```

## Does v1.0 sync links between devices?

No. Cloud synchronization is not part of v1.0.
