# SaveBuddy

## Save useful links. Keep them organized.

SaveBuddy is a lightweight Chrome extension for saving and managing useful web links directly from your browser.

**Current version:** `v1.0`

[Get Started](getting-started.md){: .btn .btn-primary }
[View on GitHub](https://github.com/gautamkaran/SaveBuddy){: .btn }

## Why SaveBuddy?

SaveBuddy keeps the workflow simple:

- Save a link manually
- Save the current Chrome tab
- Edit saved links
- Copy URLs
- Delete individual links
- Delete all links
- View website favicons
- Open the extension with a keyboard shortcut
- Keep saved data locally
