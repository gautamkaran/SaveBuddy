# Getting Started

SaveBuddy is a lightweight Chrome extension for saving and managing useful
web links directly from Chrome. It is designed around one simple workflow:
**save a useful page now, and find it again later**.

## What problem does it solve?

Browsing the web produces a long list of pages worth revisiting — tutorials,
reference docs, articles, tools. SaveBuddy gives you a fast, lightweight way
to keep those links without a full bookmark manager or an account.

## What SaveBuddy does

- Save a URL manually, with an optional title.
- Save the currently active Chrome tab with one click.
- Edit the title or URL of a saved link.
- Copy a saved URL to the clipboard.
- Delete an individual link, or all links at once.
- Show website favicons next to saved links.
- Open the extension with a keyboard shortcut.
- Store everything locally in your browser.

## Basic workflow

1. **Install** SaveBuddy as an unpacked extension (see
   [Installation](installation.md)).
2. **Save a link** — enter a URL and optional title, or click **SAVE TAB** to
   save the page you are on (see [Usage](usage.md)).
3. **Manage your links** — edit, copy, or delete links from the popup whenever
   you need them.
4. **Open it quickly** — use the keyboard shortcut (default `Alt+S`) or the
   toolbar icon.

## Current version

**v1.0** — this is the initial release of SaveBuddy.

## Requirements

- **Google Chrome** — SaveBuddy is a Manifest V3 Chrome extension.
- **The SaveBuddy source code** — the extension is distributed as source and
  installed as an unpacked extension. There is no Chrome Web Store listing at
  this time.
- **No account required** — SaveBuddy works fully offline and locally.
