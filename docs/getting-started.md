# Getting Started

SaveBuddy is designed around a simple workflow: **save a useful page now and find it again later**.

## What you can do

1. Save a URL manually.
2. Save the currently active Chrome tab.
3. Edit a saved link.
4. Copy a URL.
5. Delete individual links.
6. Delete all saved links.

## Current release

**v1.0**

This is the initial release of SaveBuddy.
