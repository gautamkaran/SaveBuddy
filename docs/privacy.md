# Privacy

SaveBuddy is designed around a local-first workflow.

## Data storage

Saved links are kept locally by the extension.

## Account

No account is required.

## Cloud sync

SaveBuddy v1.0 does not provide cloud synchronization.

## Backend

The core extension does not require a backend service.

## Favicons

Website favicon resources may be requested so saved links can display website icons.
