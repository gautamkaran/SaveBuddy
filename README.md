# SaveBuddy 🔖

A simple Chrome extension to save and manage your favorite links.

## Features

- 📌 Save links with custom titles
- 🔖 Save current tab with one click
- ✏️ Edit link titles and URLs
- 📋 Copy URLs to clipboard
- 🗑️ Delete individual links or all at once
- 💾 Data stored locally on your computer

## Installation

1. Go to `chrome://extensions/`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked** and select the SaveBuddy folder
4. Done! Extension will appear in your toolbar

## How to Use

- **Save Link**: Enter URL → Click SAVE LINK
- **Save Tab**: Click SAVE TAB to save current tab
- **Edit**: Click pencil icon → modify → Save
- **Copy**: Click copy icon to copy URL
- **Delete**: Click trash icon or DELETE ALL

## Tech Stack

- HTML5, CSS3, JavaScript
- Chrome Extension API
- Local Storage

## Privacy

✅ Data stored locally - No cloud sync, No tracking, No personal data collection
